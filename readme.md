# 🗺️ Spatial DB APIs with FastAPI & PostGIS
A backend project built with **FastAPI** to store, update, and retrieve **point** and **polygon** spatial data using **PostgreSQL + PostGIS**.

---

## 🧱 Tech Stack

- Python 3.10
- FastAPI
- PostgreSQL + PostGIS
- SQLAlchemy + GeoAlchemy2
- Docker + Docker Compose
